# 직업 옷입히기 클립아트 놀이

맨몸 캐릭터에게 다양한 직업 의상을 드래그 앤 드롭으로 입히면 캐릭터가 변신하고, 해당 직업에 대한 설명을 보여주는 어린이용 웹 놀이입니다.

## 실행 방법

별도 빌드 과정 없이 정적 파일로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어 확인합니다.

## 기능

- 의사, 소방관, 요리사, 우주비행사, 과학자 의상 카드 제공
- 의상 카드를 캐릭터 영역으로 드래그 앤 드롭하여 변신
- 마우스 드래그가 어려운 사용자를 위한 클릭 선택 및 키보드 Enter/Space 적용 지원
- 선택한 직업의 역할을 어린이가 이해하기 쉬운 문장으로 설명
